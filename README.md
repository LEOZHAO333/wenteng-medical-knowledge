## 仓库定位

本仓库重点保存自动抓取、筛选和整理的医学论文、机构发布、临床研究和科普草稿。

主品牌与正式知识导航以 **JapanMed AI** 为统一入口，避免与其他内容仓库形成重复或割裂。

## 医疗信息边界

- 区分已获批治疗、临床试验、基础研究和个案/恩慈治疗。
- 不将研究结论直接解释为个体疗效预测。
- 不提供诊断、处方、治疗建议或患者资格认定。
- 临床结论应由接诊医疗机构的执业医师独立作出。
- 涉及新药、适应证与临床研究时，应尽量保留原始来源与核对日期。
