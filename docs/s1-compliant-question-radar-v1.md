# S1 合规真实问题雷达｜执行规格 V1.0

状态：Draft；仅供内部执行与审核；不改变任何生产部署、索引或医学审核门槛。
日期：2026-10-20

## 禁用边界
- 公司业务不下载、不运行、不部署 MediaCrawler，也不将其用于商业选题或数据采集。
- 不借用 Chrome 登录状态、Cookie、扫码账号、模拟登录或绕过平台限制。
- 不批量抓取个人信息，不搜集个人微信号，不购买数据，不扩张第三方访问权限。

## 数据来源与优先级
S0-A 自有 Google Search Console / 百度搜索资源平台：在账户已授权、数据可读取时，记录搜索查询、目标页面、曝光、点击、CTR、统计区间和数据来源。未连接或无数据时标记“待接入”，不得编造。
S0-B 自有客户咨询：仅在合法可用范围内，由负责人每周整理匿名问题，不上传聊天原文、姓名、联系方式、病历、精确时间地点等可识别信息；稀有个案需抽象为通用问题。
S1-A 知乎/百度公开搜索建议与相关搜索：人工观察、少量记录词条、平台、观察日期；不使用自动爬虫。
S1-B 公众号/百家号自有后台：记录文章、阅读表现、可见搜索来源、统计时间；仅使用平台实际提供的字段。

## 每周输出格式
每条记录字段：领域（日宠通/人医）、匿名问题、来源类型、来源日期/统计窗口、搜索意图、出现频次（未知则留空）、现有页面匹配、内容缺口、医学风险等级、证据核验状态、拟采取动作、复核人/日期。
- 去重以语义与搜索意图为准；不为增加数量制造新文章。
- 先优化现有合格文章，再考虑新增；保留原始来源追溯但不保存敏感聊天记录。
- 客户咨询不可当医学证据；所有临床、药品、毒性、急症内容必须独立核对权威原始资料。
- 人医与兽医独立管理，不混库。
- Draft/Hold/noindex/未经兽医审核内容不因进入选题表而取得发布资格。

## S1 流程与验收
1. 检查自有搜索后台可用性与现有数据（未授权则登记阻断）。
2. 汇总匿名客户问题；人工补充公开搜索联想。
3. 归一化、去重、与现有FAQ/Slug匹配，形成“优先优化/新增候选/暂缓”清单。
4. 对医学相关候选实施来源核验及专业审核门槛。
5. 仅对已经批准且已公开的页面做搜索表现复盘；不宣称被收录。

验收：数据来源可追溯；隐私最小化；不使用禁用工具；无重复虚构选题；无自动发布、无权限扩大、无销售转化改动。
