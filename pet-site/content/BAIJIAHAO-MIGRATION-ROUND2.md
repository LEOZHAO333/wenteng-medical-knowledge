## 本轮结构性结论
百家号旧内容最值得回收的不是“日本兽医提醒”这类包装，而是已经验证过的搜索问题：
1. 猫慢性肾病：饮水 → 脱水 → 皮下补液 → 补液异常 → 长期管理
2. 犬皮肤脱毛：局部秃毛 → 尾部脱毛 → 瘙痒/感染/寄生虫 → 基础检查
3. 犬寄生虫：看到虫体 → 粪检 → 不同寄生虫 → 驱虫方案由兽医决定
4. 体重变化：狗突然消瘦 → 饮食/消化/肾脏/内分泌/肿瘤等分流

这些旧内容后续都按“直接答案 + 需要观察什么 + 何时就医 + 就诊准备 + 相关问题”重构，不保留旧平台式夸张标题。
