# JapanMed AI 首页宠物内容迁移规则

日期：2026-10-17
状态：Locked for upcoming homepage redesign / pet site remains Draft + noindex

## Founder决定

JapanMed AI 首页即将重新调整。调整后的**人类医疗主站首页不再出现宠物医疗内容**。

首页现有或后续发现的宠物医疗相关内容，不删除资产价值，而是统一迁移到日宠通独立宠物数据库与 `/pet/` 内容体系。

## 必须迁移的内容

凡属于以下范围，全部归入日宠通：

- “日宠通”品牌介绍、标题、摘要
- 日本宠物医疗相关说明
- 日本宠物新药相关说明
- 犬猫健康、疾病、慢病管理内容
- 宠物药品核对与官方资料说明
- 宠物第二意见、原始影像、病理、化验资料准备
- 宠物FAQ、文章入口、专题卡片
- 宠物相关SEO标题、Meta Description、关键词
- 宠物板块图片与未来可复用的非商业视觉资产

迁移后的内容必须进入统一宠物内容源，不能继续在主站首页维护第二份副本。

## 首页改版完成后的硬规则

JapanMed AI 首页：
- 不出现“宠物医疗”板块；
- 不出现“宠物新药”卡片；
- 不出现犬猫疾病或宠物药品内容；
- 不使用宠物SEO关键词承接主站首页主题；
- 不设置宠物购买、问诊或跨境医疗入口。

日宠通 `/pet/`：
- 独立品牌；
- 独立导航；
- 独立知识库；
- 独立专题体系；
- 独立 sitemap / llms.txt / 内链；
- 继续使用 JapanMedAI.com 母域下的 `/pet/` 路径，但内容主题完全独立。

## 数据源规则

所有宠物内容执行：

`唯一ID → canonicalSlug → 单一正文源 → relatedIds → /pet/ 页面渲染`

禁止：
- 首页与 `/pet/` 各维护一份不同正文；
- 同一宠物主题建立两个永久URL；
- 为了主站流量把宠物关键词重新塞回人类医疗首页；
- 首页删除宠物模块后，又在其他首页区块换名称重复出现。

## 迁移校验清单

首页正式改版前后必须检查：

1. 原宠物板块所有可复用文字已进入日宠通内容源；
2. 宠物板块相关标题、摘要、FAQ不再残留于主站首页代码；
3. 主站首页 title / description / headings 不含宠物医疗主题词；
4. 宠物内容 canonical 只指向 `/pet/`；
5. sitemap 中宠物URL只由日宠通体系生成；
6. 若存在历史独立宠物URL，再逐条决定301映射，不能一律重定向首页；
7. 主站首页改版与日宠通上线是两件独立动作，日宠通仍需Founder明确批准后才解除 noindex。

## 当前执行状态

- 日宠通内容库继续建设和医学复核；
- 已建立独立品牌介绍内容源 `PET-BRAND-INTRO.md`；
- JapanMed AI 首页本轮**暂不直接改代码**，等待即将进行的首页整体调整时一次性移除宠物医疗模块；
- 在首页改版前，先确保宠物内容已迁移，避免“先删首页、后找不到原内容”。
