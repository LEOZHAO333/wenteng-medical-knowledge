# 日宠通 P0生产逐篇索引闸门｜实施与回滚交接 V1（2026-10-27）

> **审批前交接稿；不是实施授权。** 本文在PR #36 Draft中，不修改生产文件、不触发部署、不扩大既有索引范围。CI通过不等于真实兽医医学签署。

## 1. 当前问题及影响范围

生产源码 `pet-site/api/pet.js` 的QA索引条件是slug存在于40篇`articles`数组；`robotsFor`将该结果同时写入HTML meta robots与HTTP `X-Robots-Tag`；`sitemap()`直接遍历全部40篇并用统一 `UPDATED` 作为 `lastmod`。5个核心入口单独列入 `CORE_INDEX_PATHS`；`new-drugs`被排除。全站 `INDEX_APPROVED` 只反映历史授权，不证明逐篇兽医签署。

现有Draft `release-policy.mjs` / `sitemap-policy.mjs` 提供候选资格函数，但生产尚未引用。源文件核对并不能证明实际线上索引、搜索引擎收录或HTTP响应状态。

## 2. 推荐分阶段实施（未来另开受控生产变更PR）

**阶段A｜独立证据清单（不改变线上行为）**

- 按40个真实slug逐条建立受控、可审计的审批清单。字段：原始ID、slug、来源与核验日期、真实执业兽医姓名/资质/签署日期及签署凭据位置、医学Hold、Founder发布批准凭据、Founder索引批准凭据、真实首次公开日期、真实最后修改日期。
- 不自动把现有 `published`、`UPDATED`、CI成功或历史全站开关迁移成审批字段；没有证据的记录一律保持未获批准。
- 独立核对核心5页是否属于已授权索引范围；QA审核不能代替核心页授权。

**阶段B｜无副作用的候选集成（仅Draft）**

- 将经核验清单与40个生产slug一一对应；找不到记录、重复slug、审核状态异常或证据不完整均Fail Closed。
- QA的HTTP robots、HTML robots和sitemap均使用同一资格集合；已授权核心页继续走独立判断；`new-drugs`保持noindex；Preview及404始终noindex。
- 每篇QA的 `lastmod` 只使用有证据的真实更新日期；未核验不得输出伪造的日期。
- 将**可公开访问**与**可被索引**分开处理；只移出sitemap不会使未获发布许可的内容自动下线。

**阶段C｜独立审核与受控上线**

- 自动化测试：40 QA逐条覆盖、缺签署、Hold、缺任一Founder批准、日期无效、slug不匹配/重复、Preview、404、核心5页、`new-drugs`及三种索引输出一致性。
- 人工复核：真实兽医逐篇签署核验；Founder明确批准变更文件、上线范围、上线时间与回滚条件。
- 获批准后才合并生产PR和部署。上线后逐URL抽查HTTP状态、`X-Robots-Tag`、HTML robots、sitemap；随后另行观察GSC/百度后台，不能用CI推断收录。

## 3. 上线前阻断条件

任一以下条件成立，不得将相应QA设为index：未取得真实执业兽医签署；医学Hold未解除；未取得Founder发布批准或索引批准；slug与审核凭据不匹配；来源或日期不可核实；生产与Preview规则不一致；sitemap和robots资格判断不一致。

**特别说明：** 把目前已可访问的QA从index改成noindex，属于实际索引策略变更，仍需Founder批准；本交接不授权立即执行。

## 4. 回滚方案与触发阈值

- 在任何获批生产变更前，记录已部署生产commit SHA、部署ID、40 QA和5核心页的索引响应基线及sitemap快照，确认可恢复的前一版本。
- 触发回滚：未经批准的QA出现`index,follow`、Hold内容进入sitemap、Preview变可索引、核心页异常大范围noindex、QA大量404/5xx、发布/索引权限记录不一致、页面内容意外泄露。
- 回滚动作须经授权：停止推广/提交新sitemap，恢复上一经批准部署，重新检查HTTP与HTML robots及sitemap，并记录故障时间、受影响slug、负责人和复核结果。
- **不可**通过回滚恢复到已知违反医学/发布权限的状态；若旧版本本身存在问题，应先采取经批准的紧急阻断策略，而不是机械回退。

## 5. Founder未来需要一次性审批的具体对象

仅在独立生产PR、真实签署台账、上线前后差异报告和回滚基线准备齐全时，提交一份明确审批包：

1. **合并范围**：生产PR号、准确commit SHA、受影响路径与QA清单。
2. **索引策略**：哪些QA可索引、哪些保持noindex；5个核心页是否维持现状；`new-drugs`继续noindex。
3. **部署与回滚**：目标环境、部署窗口、回滚版本、负责人和触发条件。
4. **专业审核**：每篇涉及医学内容的真实兽医签署记录；无记录者不得冒称通过。

Founder未明确批准前，PR保持Draft，生产渲染器与站点索引行为不动。
