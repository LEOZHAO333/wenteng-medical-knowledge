# 日宠通｜执业兽医医学复核交接规范 V2.2

建立日期：2026-10-18；状态：**Draft / 尚无已核实的真实执业兽医签署 / noindex / 不发布**  
本文件是**专业审稿准备材料**，不是医学评审结论或对内容公开发布的授权。

## 1. 完成与未完成必须分开

- **582条不同正文ID/Slug**：S级232、A级350；与 **582条不同ID的编辑来源台账**均关联成功（Batch01–27），批次不得再为凑数量重复新增。
- **编辑审核覆盖100% ≠ 所有正文逐句医学事实审核100%**。既有部分批次只核对明确指定的医学主旨及其来源；其他句子、范围、措辞、网页版本仍应复查。
- GitHub只读CI可以校验ID、文件路径、审核记录完整性、URL格式和授权字段，不能代替兽医临床判断，也不能确认全部网页链接在未来永久可用。
- 真实执业兽医医学签署：**本轮无可证实的新增批准**。绝不可自动把任何记录的medicalReviewStatus设为approved、让页面索引或修改现有诊疗结论。

## 2. 风险分流（自动初筛，仅用于排序）

`node pet-site/seo/medical-review-handoff.mjs --check` 从真实主库原标题生成P0/P1/P2交接优先队列，包含原始正文路径及来源复核批次路径。

- **P0_TRIAGE**：标题可能涉及急性梗阻、持续干呕、抽搐等时间敏感情况。要求专业人员核对「何时应急诊」「哪些家庭操作禁止」「何种表述可能延误就诊」。
- **P1_TRIAGE**：处方、术后护理、补液、疫苗、药品副作用、日本监管、肿瘤等非机械可判定问题。
- **P2_TRIAGE**：一般疾病科普、宠物行为和主人沟通。仍须逐句核对不夸大、不虚构事实或专家意见。
- **规则升级案例**：0465「睡觉抖腿和抽搐区别」与0480「长期抗癫痫药复查」是鉴别与慢病问题，不能仅因为标题出现“抽搐”就误划为正在发生的P0急症。已单独改作P1初筛；仍需兽医核对医学断言。

## 3. 专业复核模板（每个ID独立填写）

| 字段 | 必须填写 |
|---|---|
| Canonical ID / Slug | 沿用现有ID与Slug，不凭标题重建URL |
| 正文版本 | 文件路径、HEAD SHA、该段落原文，保留修订diff |
| 核查主张 | 一句一条拆分：诊断/急诊/剂量/药品批准/家庭护理 |
| 适用范围 | 物种、年龄、相关共病、地域/监管辖区 |
| 来源 | 官方/学协会/兽医教材原始URL、具体章节、核对日期 |
| 事实核对结果 | supported / needs_revision / insufficient_evidence / not_applicable |
| 医学风险 | 禁忌的居家操作、急诊提示、替代临床评估的误导 |
| 兽医审稿 | **真实审稿人姓名、职业资格及适用执照辖区、审核日期、签署凭据** |
| Founder批准 | 另立出版批准与SEO索引批准，不允许由医审签署代替 |
| 发布后 | 下次来源复核日期与撤回/修订路径 |

无真实审稿签署时统一为 `medicalReviewStatus=pending`；来源不足则在专业审稿队列中 `hold` 对应**主张**，不用“审核已完成”混淆状态。
